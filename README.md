# MentalChat16K - Linguistic & Therapeutic Analysis

This project analyzes the **MentalChat16K dataset** to evaluate therapeutic quality, linguistic features, and AI-generated therapeutic ratings. It combines machine learning and natural language processing to understand patterns in mental health conversations.

---

## 📊 Project Overview

This analysis examines:
- **Therapeutic Quality Assessment** - Multi-rater evaluation of conversation quality
- **Linguistic Features** - Analysis of language patterns and communication styles
- **AI Therapeutic Ratings** - Machine learning predictions of therapeutic effectiveness
- **Data Anomalies** - Identification of outliers and inconsistencies in the dataset

---

## 📁 Project Structure

| File | Description |
|------|-------------|
| `MC16k_AI_TherapeuticRating.ipynb` | AI model for predicting therapeutic ratings |
| `MC16k_MultiRater_Quality.ipynb` | Multi-rater quality assessment analysis |
| `MentalChat16k_LinguisticFeatures.ipynb` | Linguistic feature extraction and analysis |
| `NewWork_MC16k_v2_5.ipynb` | Extended analysis and feature engineering |
| `Anomalies in MentalChat16K.txt` | Identified data anomalies and inconsistencies |

## 🛠️ Requirements

- Python 3.8+
- Jupyter Notebook
- Key libraries:
  - `pandas` - Data manipulation
  - `numpy` - Numerical computing
  - `scikit-learn` - Machine learning
  - `matplotlib` & `seaborn` - Data visualization
  - `nltk` - Natural language processing
  - `openai` - API integration (if using GPT features)

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Jacksonbond-haizz/ARP.git
cd ARP
```

### 2. Install Dependencies
```bash
pip install pandas numpy scikit-learn matplotlib seaborn nltk
```

### 3. Run Notebooks
Open any `.ipynb` file in Jupyter:
```bash
jupyter notebook MC16k_AI_TherapeuticRating.ipynb
```
